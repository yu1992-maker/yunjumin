英國 eVisa 與 share code:開戶、租房怎麼證明身份

2026 年 10 月 30 日約 5 分鐘讀完雲居民論壇編輯部

英國 eVisa 是純線上記錄,開戶和租房要靠 share code 證明身份。本文講怎麼生成、給誰用、有效期,以及銀行拒收時怎麼辦。

英國的 eVisa 是只存在於網上的身份和移民身份記錄,沒有實體卡。開戶或租房時,你要在 GOV.UK 的 View and Prove 服務里生成一個 share code,把它和出生日期一起發給銀行或房東,對方在官網上輸入就能核對。租房和開戶用的是不同用途的 code,不能混用。

先搞清楚:eVisa 和 share code 是什麼

  • eVisa:英國內政部(UKVI)保存的線上記錄,內容是你的身份和移民身份。官方給金融機構的指引說,它屬於 2010 年《身份證件法》第 7 條下的身份證件,包含姓名、出生日期和國籍。
  • share code:你在 View and Prove 服務里生成的一串代碼,限時有效。對方憑 code 加你的出生日期,在 GOV.UK 查你的當前狀態,同時會看到與證件關聯的面部照片。
  • 實體卡(BRP/BRC):正在被 eVisa 取代。官方說,持有效 BRC 的人同時有 eVisa,卡上的信息“可能已不準確”。

第一步:建好 UKVI 賬戶

  1. 準備好證件信息(護照或 BRP 的詳情)、出生日期,以及能收驗證碼的手機或郵箱。
  2. 在 GOV.UK 登錄或註冊 UKVI 賬戶。
  3. 如果你換過護照或登錄信息,要用更新後的資料登錄。
  4. 姓名、國籍、證件有變動,要及時更新。
  5. 資料有誤或進不去賬戶,聯繫 UKVI Resolution Centre:電話 0300 790 6268(週一至週五 8:00–20:00,週末 9:30–16:30,英國時間);用不了 0300 號碼的,打 +44 (0)203 875 4669。

第二步:按用途生成 share code

官方說明,code 只能用於你生成時選擇的用途。給房東的 code 不能給雇主用,反過來也一樣。

場景生成時選的用途對方在哪裡查
租房(英格蘭)租房(right to rent)房東或中介用“View a tenant's right to rent in England”
開銀行賬戶“something else”(其他)銀行用“Check someone's immigration status”
找工作工作(right to work)雇主用“View a job applicant's right to work details”

開戶選“something else”這一點,來自民間組織 the3million 的說明,GOV.UK 的頁面本身沒寫得這麼細。該組織還說,這類 code 以 S 開頭。

有效期:30 天還是 90 天

各來源說法不一。GOV.UK 面向歐盟公民的指南寫的是 90 天,期間可以重復使用,生成新 code 不會讓舊 code 失效。但一份較早的服務說明和愛丁堡大學的指南寫的是 30 天。較早的版本可能已經過時,但本站沒找到官方改期的公告。實際以你在服務頁面看到的有效期為準。

官方給金融機構的頁面沒寫具體天數,租房頁面也沒有。

租房時怎麼做

  1. 登錄 View and Prove,選擇“證明你的租房權利”。
  2. 生成 code,連同出生日期發給房東或中介。
  3. 對方在官網輸入後,就能看到你能不能租、能租多久。
  • GOV.UK 頁面名稱是“Prove your right to rent in England”。官方指南說,房東和中介用的是“in England”的服務,其他地區(蘇格蘭、威爾士、北愛)是否適用,頁面沒有明確說明。
  • 用 code 是一種選擇。你也可以拿符合條件的證件原件讓房東核對,房東不能僅因為你沒用 code 就拒絕。
  • 用護照里的簽證貼紙(vignette)作為居留權證明的人,不能用這個服務。
  • BRP 過期後,官方租房頁面說,實體卡在到期日後 18 個月內仍可使用。

開銀行賬戶時怎麼做

  1. 先問銀行是否接受 eVisa 加 share code。一些大學提醒,並非所有銀行都熟悉這套流程。
  2. 生成 code(用途選“something else”)。
  3. 把 code 和出生日期發給銀行,銀行在官網核對。
  4. 如果銀行要求你出示實體 BRP,把官方指引《Residence documents: information for financial providers》發給他們。

有高校提醒,在英國只待 6 個月以內的人,部分銀行可能不給開戶,線上銀行通常更靈活。這是學校的建議,不是官方規定。

銀行拒收怎麼辦

  • the3million 說,確實有銀行和金融機構拒收 share code 或 eVisa。
  • 先拿出官方金融機構指引,請對方走內部合規流程。
  • 仍被不公平對待,可以向 Financial Ombudsman 投訴,並向 the3million 報告。

常見問題

問:沒有 BRP 卡,怎麼證明身份?

用 eVisa 加 share code。官方說,收到的身份狀態書面通知不能用作工作權利或獲取服務的證明,只供自己留存。

問:同一個 code 能給多個房東用嗎?

官方說,有效期內同一個 code 可以重復使用,生成新 code 不會讓舊的作廢。但用途要選對,租房 code 只能用於租房。

問:有實體證件但登錄不了 View and Prove 怎麼辦?

官方說,持有 BRC/P 等實體證件又進不了服務的人,可以用該證件證明身份。出行時也要隨身帶實體證件。

以上內容基於 2026 年 10 月查到的公開資料。政策和服務細節可能變化,請以 GOV.UK 官方頁面為準;涉及複雜的移民或租約問題,請咨詢移民律師或持牌顧問。
