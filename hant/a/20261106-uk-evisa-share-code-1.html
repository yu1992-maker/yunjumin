英國 eVisa Share Code 是什麼:開戶和租房怎麼給銀行看

2026 年 11 月 6 日約 4 分鐘讀完雲居民論壇編輯部

Share Code 是證明英國移民身份的臨時代碼,有效 90 天。本文講怎麼生成、租房和銀行開戶各選哪種,以及銀行不認時怎麼辦。

Share Code(分享碼)是英國政府給 eVisa 持有人的臨時代碼,用來向第三方證明你的移民身份,不用出示實體證件。對方拿到代碼和你的出生日期,就能到官方網站核對。官方說明代碼有效期 90 天,期間可重復使用。

開戶和租房都能用,但要選對類型:租房用“證明租房權利”的碼,銀行開戶用“其他用途(something else)”的碼。

Share Code 是什麼

  • GOV.UK 的定義:這是一個臨時代碼,讓你證明移民身份,而不必出示 eVisa 本身。
  • 對方還需要你的出生日期。
  • 代碼有效期 90 天,期間可以使用多次;過期後可以重新生成。
  • 生成時,系統會告訴你對方能看到哪些個人信息。

怎麼生成:步驟

  1. 登錄 UKVI 賬戶,進入“View and prove your immigration status”(查看和證明移民身份)服務。
  2. 準備好以下任一證件:護照、國民身份證、生物信息居留卡(有效或過期均可)、過期的生物信息居留許可,或 UKVI 客戶編號。
  3. 確保能收到賬戶綁定的手機短信或郵件驗證碼。
  4. 選擇證明身份的用途,系統生成代碼。
  5. 把代碼和出生日期發給對方,不需要給對方看 eVisa。

如果進不了賬戶,GOV.UK 建議先確認 UKVI 賬戶已設置完成,或改用其他方式證明工作或租房資格。

租房:給房東看

  • GOV.UK 的租房頁面說明,非英國、非愛爾蘭公民可以用 Share Code 或原始移民文件證明租房權利,由你選擇。
  • 房東不能只因為你出示的是合格的移民文件、而不是 Share Code 就拒絕你。
  • 如果你無法證明,房東可以向內政部申請租房權利核查。
  • 租房頁面沒有寫具體交碼步驟和有效期,有效期以前面的 90 天為準。

銀行開戶:給銀行看

GOV.UK 的 Share Code 頁面只舉了雇主、房東和出行的例子,沒有提到銀行。銀行場景的細節來自民間組織 the3million 的說明。

  1. 在 View and prove 服務里點“prove your status”(證明你的身份)。
  2. 原因選“something else”(其他)。
  3. 據 the3million,這類代碼以字母 S 開頭,有效期 90 天。
  4. 把代碼和出生日期給銀行,銀行在政府的核查頁面查詢。
注意:the3million 提醒,這種“其他用途”的代碼不能用於工作權利或租房權利核查。租房和開戶要分別生成。

銀行不認怎麼辦

  • 據 the3million,有的銀行或建房互助會會拒收 Share Code。
  • 可以請對方查閱政府指引 “Residence documents: information for financial providers”,該指引說 eVisa 可證明身份和移民身份。
  • 如果覺得被不公平對待,可向 Financial Ombudsman(金融申訴專員)投訴,也可向 the3million 反映。

銀行地址證明的問題

新到英國的人開戶,傳統銀行往往還要求英國地址證明。UCL 的指引提到,多數銀行不接受酒店、青旅作為地址。幾家學校和援助機構的指南提到 Monzo、Starling、Revolut、Monese 等數字銀行相對靈活,但各家要求會變,說法也不一,申請前要看銀行官網當前的證件清單。

常見問題

問:Share Code 過期了怎麼辦?

重新生成即可。官方說明可隨時獲取新代碼。

問:一個代碼能同時給房東和銀行用嗎?

不建議。據 the3million,“其他用途”的代碼不能用於租房或工作核查,所以按用途分別生成。

問:銀行說必須看實體證件怎麼辦?

先請銀行查官方核查頁面,並出示上面提到的政府金融機構指引。仍被拒絕的,可考慮向金融申訴專員投訴,或換一家銀行。

以官方為準,複雜情況請咨詢持牌移民律師或 CPA。本文不構成法律意見。
