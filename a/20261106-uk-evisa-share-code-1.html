英国 eVisa Share Code 是什么:开户和租房怎么给银行看

2026 年 11 月 6 日约 4 分钟读完云居民论坛编辑部

Share Code 是证明英国移民身份的临时代码,有效 90 天。本文讲怎么生成、租房和银行开户各选哪种,以及银行不认时怎么办。

Share Code(分享码)是英国政府给 eVisa 持有人的临时代码,用来向第三方证明你的移民身份,不用出示实体证件。对方拿到代码和你的出生日期,就能到官方网站核对。官方说明代码有效期 90 天,期间可重复使用。

开户和租房都能用,但要选对类型:租房用“证明租房权利”的码,银行开户用“其他用途(something else)”的码。

Share Code 是什么

  • GOV.UK 的定义:这是一个临时代码,让你证明移民身份,而不必出示 eVisa 本身。
  • 对方还需要你的出生日期。
  • 代码有效期 90 天,期间可以使用多次;过期后可以重新生成。
  • 生成时,系统会告诉你对方能看到哪些个人信息。

怎么生成:步骤

  1. 登录 UKVI 账户,进入“View and prove your immigration status”(查看和证明移民身份)服务。
  2. 准备好以下任一证件:护照、国民身份证、生物信息居留卡(有效或过期均可)、过期的生物信息居留许可,或 UKVI 客户编号。
  3. 确保能收到账户绑定的手机短信或邮件验证码。
  4. 选择证明身份的用途,系统生成代码。
  5. 把代码和出生日期发给对方,不需要给对方看 eVisa。

如果进不了账户,GOV.UK 建议先确认 UKVI 账户已设置完成,或改用其他方式证明工作或租房资格。

租房:给房东看

  • GOV.UK 的租房页面说明,非英国、非爱尔兰公民可以用 Share Code 或原始移民文件证明租房权利,由你选择。
  • 房东不能只因为你出示的是合格的移民文件、而不是 Share Code 就拒绝你。
  • 如果你无法证明,房东可以向内政部申请租房权利核查。
  • 租房页面没有写具体交码步骤和有效期,有效期以前面的 90 天为准。

银行开户:给银行看

GOV.UK 的 Share Code 页面只举了雇主、房东和出行的例子,没有提到银行。银行场景的细节来自民间组织 the3million 的说明。

  1. 在 View and prove 服务里点“prove your status”(证明你的身份)。
  2. 原因选“something else”(其他)。
  3. 据 the3million,这类代码以字母 S 开头,有效期 90 天。
  4. 把代码和出生日期给银行,银行在政府的核查页面查询。
注意:the3million 提醒,这种“其他用途”的代码不能用于工作权利或租房权利核查。租房和开户要分别生成。

银行不认怎么办

  • 据 the3million,有的银行或建房互助会会拒收 Share Code。
  • 可以请对方查阅政府指引 “Residence documents: information for financial providers”,该指引说 eVisa 可证明身份和移民身份。
  • 如果觉得被不公平对待,可向 Financial Ombudsman(金融申诉专员)投诉,也可向 the3million 反映。

银行地址证明的问题

新到英国的人开户,传统银行往往还要求英国地址证明。UCL 的指引提到,多数银行不接受酒店、青旅作为地址。几家学校和援助机构的指南提到 Monzo、Starling、Revolut、Monese 等数字银行相对灵活,但各家要求会变,说法也不一,申请前要看银行官网当前的证件清单。

常见问题

问:Share Code 过期了怎么办?

重新生成即可。官方说明可随时获取新代码。

问:一个代码能同时给房东和银行用吗?

不建议。据 the3million,“其他用途”的代码不能用于租房或工作核查,所以按用途分别生成。

问:银行说必须看实体证件怎么办?

先请银行查官方核查页面,并出示上面提到的政府金融机构指引。仍被拒绝的,可考虑向金融申诉专员投诉,或换一家银行。

以官方为准,复杂情况请咨询持牌移民律师或 CPA。本文不构成法律意见。
