2026-11-03 · 第一期：先建“回忆”习惯，再谈背诵量

当天学完，先合上书默写一遍要点，再对照补漏。默写时想不起来，正是记忆在加固的信号，不是失败。把这个动作固定成每天最后一件事，比多看两遍更划算。

记忆方法库

01 — MEMORY
01

主动回忆

不看答案先答：自问自答、默写提纲、给别人讲一遍。每次回忆都是一次提取练习，效果远好于反复阅读。

做法：学完一个小节 → 合书列出 3 个要点 → 对照原文补漏 → 第二天再默一次。

02

间隔重复

在快要忘记时复习，间隔越拉越长：当天 → 次日 → 3 天后 → 一周后 → 两周后。只复习上次没答对的部分，答对的往后推。

03

费曼技巧

用最简单的话讲给外行听，讲不通的地方就是没真懂，回去补那一块，再讲一遍。适合概念题、申论论点和政策类知识。

04

联想与记忆宫殿

把抽象条目挂在熟悉的地点或画面上：进门是第一点，客厅是第二点。适合背顺序、清单和多条并列的知识点，平时少用、关键清单再用。

05

交错练习

不要一整天只练一种题型，把几种题型混在一起练。开始会觉得难，但考试时分辨“这题用什么方法”的能力就是这样练出来的。

06

睡眠是复习的一部分

熬夜背完第二天忘得更快。重要内容尽量在白天学完、晚上睡前快速过一遍提纲，然后睡觉，让睡眠帮你巩固。

考试技能库

02 — EXAM SKILLS

审题三步

① 划出题干的限定词（时间、范围、主体）；② 先判断题型再动笔；③ 选择题先排除明显错项，再在剩下两项里比对题干原话。

时间分配

开考前先按题量定每部分预算，单题卡住超过预算就先标记跳过，做完回头再攻。最后留 5 分钟检查涂卡、姓名和漏题。

错题复盘模板

每道错题只记四行：原题要点 / 我当时怎么想的 / 正确思路差在哪 / 下次同类题第一步做什么。复盘 20 道胜过新刷 100 道。

模拟考试流程

每周一次全真模拟：掐表、关手机、按真实顺序做、做完立刻对答案并复盘，不要只做半套就停。模拟的意义是练节奏，不是练手感。

考前 7 天

不再开新书：只过错题本、提纲和模拟卷错点；每天保持一套题的手感；提前查好考点路线、证件和文具，考前一天早睡。

动手练一下：自测卡片

问题：今天学完，最有效的第一步是什么？（点我看答案）

答案：合上书，先默写一遍要点，再对照补漏。这就是主动回忆。
